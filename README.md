# Automatic Street Light Using LDR and Arduino

An Arduino-based automatic streetlight system that detects
ambient light using an LDR sensor and automatically controls
an LED.

## Features
- Automatic ON/OFF control
- LDR-based light detection
- Arduino Uno microcontroller
- Simple and low-cost circuit
- Energy-efficient lighting concept

## Components
- Arduino Uno
- LDR sensor
- 10kΩ resistor
- 330Ω resistor
- LED
- Breadboard and jumper wires

## Working Principle
The LDR senses the surrounding light level. Arduino reads
the sensor value and compares it with a predefined threshold.
The LED turns ON in darkness and OFF in bright conditions.

## Applications
- Automatic streetlights
- Garden lighting
- Home entrance lighting
- Energy-saving lighting systems
